# Ejemplo común: reserva de salas

Dominio del curso. Un centro con tres salas que se reservan por franjas de 30 a 120 minutos entre las 08:00 y las 21:00.

| Fichero | Qué es | Cuándo se usa |
|---------|--------|---------------|
| [`docs/prd.md`](docs/prd.md) | PRD del ejemplo | Sesión 2 en adelante |
| [`docs/specs/A-crear-reserva/spec.md`](docs/specs/A-crear-reserva/spec.md) | Spec de **referencia** de la feature A. **No se mira antes de escribir la propia** (sesión 3) | Sesión 3, parte C |
| [`docs/specs/A-crear-reserva/plan.md`](docs/specs/A-crear-reserva/plan.md) y [`tasks.md`](docs/specs/A-crear-reserva/tasks.md) | Plan y tasks de referencia de A, con las firmas | Para comparar en la sesión 4 |
| [`docs/specs/B-cancelar-reserva/spec.md`](docs/specs/B-cancelar-reserva/spec.md) | Spec aprobada de B | Sesión 5 |
| [`docs/specs/C-consultar-reservas/spec.md`](docs/specs/C-consultar-reservas/spec.md) | Spec aprobada de C | Sesión 6 |
| [`docs/specs/README.md`](docs/specs/README.md) | Índice de features | Sesiones 5 y 6 |

No hay código: cada persona construye el ejemplo en la tecnología de su módulo.
