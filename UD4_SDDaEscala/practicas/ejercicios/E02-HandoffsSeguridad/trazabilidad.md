# Acciones

Seis acciones que pueden ocurrir en el flujo de la feature D. Decide quién debe ejecutarlas.

| # | Acción |
|---|--------|
| 1 | Cambiar el estado de la spec de D de `En revisión` a `Aprobada` |
| 2 | Escribir el código de `servicio-prestamos.js` |
| 3 | Fusionar la rama `feature/D-registrar-devolucion` en `main` |
| 4 | Buscar en el código dónde se crea `ErrorNoEncontrado` |
| 5 | Subir una dependencia nueva a `package.json` |
| 6 | Actualizar el `README.md` con la nueva ruta de la API |
